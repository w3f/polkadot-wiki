### **Block Explorers**

There are several block explorers that you can use to explore Polkadot, Kusama, and other Substrate chains and parachains. Here is a list of them, which will be updated as more are developed.

EXPLORER| RELAY CHAINS| PARACHAINS| OTHER
---|---|---|---
[Subscan](https://www.subscan.io/)| Polkadot and Kusama| Yes| Testnets, XCM transfers
[Statescan](https://www.statescan.io/)| Kusama| Yes| NFT, testnet
[Singular](https://singular.app/)| -| -| NFT explorer and marketplace
[KodaDot](https://kodadot.xyz/)| -| -| NFT explorer and marketplace (RMRK and Basilisk)

!!! info

    These block explorers are not developed or maintained by Web3 Foundation. If you encounter an issue while using them, please contact their respective team.
