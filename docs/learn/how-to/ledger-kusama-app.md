title: "Ledger: Can I Use the Ledger Polkadot App for Kusama?"
description: "Use the Polkadot Ledger app to easily interact with the Kusama network—no need for a separate Ledger app anymore!"
---

!!!info "Related concepts"
    For the underlying concepts, see [Ledger](../../general/ledger.md).

_The Polkadot Ledger app can interact with any compatible Substrate-based network since version 100.0.0. That means you can now use the Polkadot app to sign from its account on multiple networks, including Kusama, and not just on Polkadot._

* * *

!!! warning "IMPORTANT"

    Ledger is phasing out support for the [Ledger Nano S](https://support.ledger.com/article/Ledger-Nano-S-Limitations). Your funds remain safe, but upgrading is recommended to ensure compatibility with future Polkadot updates.

    Notice that other Ledger models (e.g., Ledger Nano S Plus) are not affected.

Legacy Ledger apps were designed to sign transactions only on their designated network, using accounts generated from the app (i.e., specific private keys and derivation paths). This limitation arose from a combination of network features and Ledger’s architecture. However, with the introduction of the Polkadot Ledger app v100.0.0, networks that have updated their runtimes can now interact seamlessly with this new app. This upgrade removes the need for separate apps for each network and eliminates the requirement for constant updates, greatly enhancing the user experience.

### What happened with the Kusama app?

In a few words, the standalone Kusama app is now obsolete. You must use either the "Polkadot Migration" app or the Polkadot app. Currently, there are now two scenarios you might face:

  * If you previously used the Kusama app (v26.x, now obsolete), download and install the "Polkadot Migration" app from Ledger Live. This will allow you to access your Kusama account and operate on the Kusama network. Then, we recommend [migrating your funds](ledger-migrate-generic-app.md) to an account generated by the new Polkadot app for better long-term support.
  * If you never used the old Kusama app, you can use the Polkadot app directly to interact with Kusama, without any additional steps. Connect your Ledger to any [compatible wallet](where-to-store-dot.md), and they will offer a friendly interface to interact with any network.
